# Ryan Rupea Portfolio

Personal portfolio site. Plain HTML, CSS and JavaScript, hosted on GitHub Pages.

## Publish on GitHub Pages
1. On GitHub, create a new public repository named exactly `NayrHigh.github.io`.
2. Click "uploading an existing file" and drag in everything from this folder
   (index.html, style.css, script.js, README.md and the images folder).
3. Commit. After a minute or two the site is live at https://nayrhigh.github.io
   (Settings → Pages shows the status; the source should be "Deploy from a branch", branch `main`, folder `/ (root)`).

## Edit later
- Text: index.html
- Colors and fonts: the `:root` block at the top of style.css
- Images: the images folder
